설치 순서
1) Supabase > SQL Editor 에서 04_day_todos.sql 전체 실행 (한 번)
2) Netlify > Deploys 에 이 폴더(또는 zip) 끌어다 놓기
3) 아이폰/아이패드: 앱을 완전히 종료 후 다시 열기 (새 버전 적용)
   아이콘이 예전 그대로면 홈 화면 아이콘을 삭제하고 사파리 > 공유 > 홈 화면에 추가 로 다시 추가
   ※ 아이콘을 지워도 데이터는 그대로지만, 불안하면 먼저 설정 > 백업·복원 > 내보내기
